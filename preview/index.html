04 / GET DRACO

あなたのホームを、
ここから。

APK形式で配布しています。Google Playを経由せず、Android端末に直接インストールできます。

  1. APKをダウンロード

    GitHub Releasesから最新の配布ファイルを取得します。

  2. インストールを許可

    Androidに確認された場合、ダウンロード元のブラウザに許可を与えます。

  3. ホームアプリに設定

    端末のホームアプリとしてDraco Launcherを選びます。

APKをダウンロード

対応：Android 10以上。個人開発のアプリです。導入前に配布条件・注意事項をご確認ください。

使う前に

現在無料で配布していますが、動作保証はありません。確認済み端末や再配布に関する条件など、詳しくは正式ページの注意事項をご覧ください。

プライバシー

基本的なホーム画面の設定は端末内に保存します。天気表示など一部機能は外部サービスを利用します。詳細は正式ページのプライバシー情報をご確認ください。
